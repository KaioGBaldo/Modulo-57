# 🐍 Django Architecture - Professional Backend Setup

Este projeto marca o início da exploração do framework **Django**, focado na configuração estrutural de um ambiente de back-end robusto. O objetivo é estabelecer uma base sólida seguindo as melhores práticas de arquitetura de software, segurança e gerenciamento de banco de dados relacional.

---

# 📝 Resumo (Resume)
Neste setup inicial, configurei o núcleo de uma aplicação Django, explorando o ecossistema de arquivos de configuração (`settings.py`), o sistema de roteamento global (`urls.py`) e a interface de linha de comando (`manage.py`). Foquei na compreensão do padrão **MVT (Model-View-Template)** e na configuração de middlewares essenciais para segurança, sessões e autenticação. A estrutura utiliza o **SQLite3** para persistência de dados inicial, permitindo uma transição fluida para bancos de dados de produção como PostgreSQL.

## 📋 Funcionalidades em Destaque
* **Configuração de Núcleo (Settings):** Gerenciamento de chaves de segurança, depuração (Debug mode) e definição de hosts permitidos.
* **Sistema de Middlewares:** Implementação de camadas de segurança contra ataques como CSRF (Cross-Site Request Forgery) e Clickjacking.
* **Roteamento Centralizado:** Estruturação de URLs globais para fácil manutenção e escalabilidade do projeto através do `ROOT_URLconf`.
* **Gerenciamento de Apps:** Preparação do ambiente para modularização, onde cada funcionalidade do sistema é isolada em um app específico.
* **Internacionalização (i18n):** Configuração de fuso horário (UTC) e suporte a múltiplos idiomas nativos do framework.
* **Utilitário de Comando:** Domínio do `manage.py` para execução de servidores de desenvolvimento, migrações de banco de dados e tarefas administrativas.
